InterAct 網頁版

開啟講師端　開啟學員端

在其他電腦使用

  1. 將整個 InterAct-Web 資料夾複製到另一台電腦，保留 assets、about 等子資料夾。
  2. 用 Chrome 或 Edge 開啟 index.html，不必執行原本的 InterAct.exe。
  3. 進入系統設定確認 Supabase 連線資訊；原設定檔的公開連線資訊已帶入 config.js。

需要麥克風、攝影機或螢幕分享時

建議透過 HTTPS 網站或 localhost 開啟。若電腦已有 Node.js，在此資料夾的終端機執行 node server.cjs，再開啟 http://localhost:8080。關閉終端機即停止伺服器。

讓多台裝置透過網址使用

將本資料夾的 index.html、config.js、web-loader.js、web.css、assets、about、caption-worklet.js 和 SVG 檔上傳至 HTTPS 靜態網站主機，保留相對路徑。學員連結應使用該 HTTPS 網址；直接開啟檔案或 localhost 產生的網址不能讓其他裝置連入。系統設定中的「學員端網址」可填已部署的 HTTPS 網址。

功能與限制

  • 保留原本教學介面、場次、學員加入、互動題型、AI 與報表程式；實際資料與 AI 功能仍需可用的 Supabase 後端與其金鑰設定。
  • 原桌面版的置頂、透明浮窗、系統最小化與原生截圖不適用於瀏覽器；網頁操作使用原程式的瀏覽器分支。
  • 網頁版不提供 Electron 專用的 Supabase 自動部署功能，後端須在 Supabase 管理平台維護。
  • 若建立場次回覆「請使用 InterAct Windows App」，代表既有後端仍限制桌面來源，需要由後端管理者開放指定 HTTPS 網址，保留管理金鑰驗證。此轉換沒有修改雲端後端權限。
  • 各瀏覽器分別儲存設定與講師權限。換電腦後，既有場次可能需要在系統設定重新輸入管理金鑰。
  • config.js 僅帶入公開 publishable key，請勿放入 service_role、secret key 或 AI 私密金鑰。

此版本由封裝程式還原並適配，沒有原始 React/TypeScript 專案。原有授權資訊保留於 about 資料夾。已檢查 JavaScript 語法；尚未驗證真實課堂與 AI 端到端操作。
